> **配套**：必须与《00-总纲-架构与硬件协议》一起投喂。本分册只定义程序 2 的专属逻辑；总纲的引脚、BLE NUS、NVS、生命周期规范全部适用。
> **状态**：逻辑已冻结；本册为编程规范。V2 中断计时版参考实现已存在（见《单摆测重力加速度全套方案.html》第五节），M1 迁移时以其为基线。
> **⚠️ 修订（2026-09-30）**：计时法已升级为**中点法**（GPIO4 改 CHANGE 双沿、遮挡中点为计时点）——以《02-程序2-单摆测g-中点法修订补丁.md》为准，本册第 2/3 节中与前沿法相关的描述相应作废，其余不变。

## 1. 职责与边界
- 职责：光电门测周期 → 计算 g（单次与平均）、联网校准当地标准 g、OLED 显示、BLE 菜单（摆长/历史/配合全局配网）
- 边界：不管理 WiFi 连接本身（走网络服务）；不写天气/桌宠任何 NVS 键；测量中收到切程序事件（用户长按）→ 走 onHide 正常挂起，**测量状态一并持久化**，切回可续测

## 2. 硬件协议速查（本程序相关）
| 项 | 值 |
|---|---|
| 光电门输入 | GPIO4，INPUT_PULLUP，**空闲高 / 遮挡低**，中断 **FALLING** = 遮挡开始 |
| 消抖 | 中断内：间隔 < 20000µs 丢弃；间隔 > 5000000µs（5s）视为基准失效，重置基准不计数 |
| 计时源 | `micros()`（中断捕获，loop 侧 noInterrupts/interrupts 临界区读取共享变量） |
| OLED | I²C 0x3C，128×64，SH1106 专用库（Adafruit_SH1106 或 U8g2）；SDA=GPIO8 SCL=GPIO9；ESP32-S3 需 Wire.begin(8,9) |
| 按键 | GPIO5；短按=开始/停止测量（管理器已拦截长按） |

## 3. 测量逻辑（状态机）
```
IDLE待机 ─短按→ MEASURING测量中 ─短按→ IDLE（保留数据显示）
MEASURING 开始时：自动清零（sumHalf/nHalf/lastT/lastG/Gavg，gateNew=false）
每个有效半周期（FALLING 中断捕获 dt）：
  halfT = dt/1e6；sumHalf += halfT；nHalf++
  lastT = 2×halfT
  快慢交替检测：|halfT − pendHalf| / 均值 > 1.5% → 置 altDetected，记 altAmp/altCnt
  配对结算（2026-10-02）：
    无挂起 → pendHalf = halfT（挂起）
    有挂起 → sumPair += pendHalf + halfT；nPair++（一快一慢 = 一个完整周期）
  Tavg  = nPair>0 ? sumPair/nPair : 2×sumHalf/nHalf
  lastG = 4π²L/lastT²（nPair>0 时用最近配对周期）
  Gavg  = 4π²L/Tavg²          ← 只用配对结果，天然免疫奇偶/丢样本
测量结束时（短按停止）：落单样本排除（nDropped=1）→ 生成历史记录 → 广播 EVT_MEASURE_DONE(g=Gavg)
```
- **为什么按对结算**：光电门不在最低点时，相邻半周期一快一慢、幅度对称，
  两两相加恒等于真实周期。故 Gavg 只取「快+慢」配对结果——
  无论 n 奇偶、是否丢样本都无偏。屏幕 `N` 显示参与平均的样本数（恒偶）。
- 历史记录字段（CSV 行，存储服务落 `app2.hist_NN`）：`序号,YYYY-MM-DD HH:MM,L,N,Tavg,Gavg,err%`
  （`N` = 参与平均的样本数 = nPair×2，非 nHalf）
- 环形容量 50 组，满后淘汰最旧

## 4. OLED 显示规范（4 行布局，字段名与原版一致，不得改动）
```
行1: g=<lastG 3位小数> m/s2
行2: n=<挡光总次数 nHalf> t=<lastT 3位小数>s
行3: L=<L 3位小数> sG=<sG 3位小数>
行4: N=<nPair×2>[*] G=<Gavg 3位小数>     ← [*] 仅当尚有落单样本未配对
角标: err=<err 2位小数>%[ *ALT<幅度>%]  [测量中]/[待机]  数据年龄小字(仅sG来自缓存时)
     （*ALT 仅在检出快慢交替时出现，提示光电门可能偏离最低点）
```

## 5. 当地标准 g（联网显示，断网降级）
- 计算：`sG = 9.780327×(1 + 0.0053024·sin²φ − 0.0000058·sin²2φ) − 3.086e-6 × h`（φ=纬度 rad，h=海拔 m；海拔默认 0，可 BLE 修改）
- 触发时机：`EVT_NET_GOT` 且坐标/海拔变更过，或缓存缺失时，后台计算一次
- 写 `app2.sg_cache / sg_src=CALC / sg_ts`；断网读缓存；从未有缓存用默认 **9.794**（sg_src=DEFAULT）
- err = (Gavg − sG)/sG × 100%

## 6. BLE 菜单（程序 2 注册项；全局 [1] 配网 [0] 状态由系统注册，见总纲）
```
[2] 摆长
    2.1 查看当前 L → INFO: L=1.050 m  n=<nHalf> 参与平均=<nPair×2> G=<Gavg>
    2.2 修改 L → 提示输入 → 校验 0.1–5.0 m → 二次确认 y/n
        → 写 app2.pend_len → OK: L 已更新 → OLED 立即刷新
    2.4 实时波形 → STREAM ON/OFF（phyphox 兼容 #STREAM 协议）
    （隐藏）altstat → 快慢交替诊断：是否检出/幅度/次数/n/参与/落单排除/G/T
    （隐藏）alt <米> → 改海拔并重算当地 sG
    SIM ON|OFF|<半周期秒> → 无光电门自测（复用同一道环形队列与全链路）
[3] 历史数据
    3.1 预览 → INFO: 共<N>组，最新: <记录摘要>
    3.2 导出全部 → 见 6.1 导出流协议
    3.3 清空 → 提示键入 CLEAR 确认 → 清空 hist_* → OK/ERR
```
### 6.1 导出流协议（BLE NUS 文本流）
```
#EXPORT BEGIN,<count>
<idx>,<datetime>,<L>,<N>,<Tavg>,<Gavg>,<err%>   ← 每组一行，共 count 行
#EXPORT END
```
规则：每行 ≤ MTU-3 字节，按 Notify 连续发送；PC 端收到 BEGIN 后缓存、END 后落盘 `pendulum_history_YYYYMMDD.xlsx` 并自动绘制 **T²–L 图**（散点 + 理论直线 T²=(4π²/g)·L，斜率反推 g 与实测对比）。

## 7. NVS 读写规则
- 摆长修改即写（`app2.pend_len`）；测量结束即写历史记录；sG 计算完成即写缓存
- onCreate 顺序恢复：pend_len → sg_* → hist 区（缺失键视为出厂状态，不报错）
