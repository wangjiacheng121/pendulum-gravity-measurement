## 1. 修订动机

原口径为**前沿法**：单 FALLING 中断，把「遮挡开始沿」当作摆球过最低点的时刻。
该口径隐含假设「遮挡前沿 ≈ 过最低点」，挡光片进出遮挡的速度不对称、挡光片宽度
带来的系统误差无法抵消。

对照原版参考实现（mcitem/pendulum-gravity-measurement，`lsw.rs`）升级为**中点法**：
取遮挡时段的时间中点作为摆球过最低点的时刻，挡光片相关系统误差被中点天然抵消，
对光电门测量是实打实的精度增强。

## 2. 计时原理（修订后）

1. GPIO4 中断改为 **CHANGE 双沿触发**（空闲高/遮挡低；极性相反时改判据）。
2. FALLING（进遮挡）记录 `t_in`；RISING（出遮挡）结算一个**计时中点**：
   `mid = t_in + (t_out − t_in) / 2`。
3. 相邻两个中点之差 = **半周期**（分离式挡光片双向过槽各挡一次）。
4. `lastT = 2 × 半周期`；`Tavg = 2 × Σ半周期 / nHalf`——与前沿法完全一致，
   仅计时点由前沿改为中点。

## 3. 消抖与基准（修订后）

| 情形 | 处理 |
|---|---|
| 遮挡持续时长 < 20ms | 判为毛刺，整对（FALLING+RISING）丢弃，不产生中点 |
| 相邻中点差 < 20ms | 异常，丢弃该差值 |
| 相邻中点差 > 5s | 停摆/重启，重置基准：当前中点只作基准不计数 |
| 遮挡中再次 FALLING（漏检 RISING） | 丢弃旧对，以新 FALLING 重新开始 |
| 首个中点 | 只建立基准，不计数 |

## 4. 字段口径（不变）

- `n` = 有效半周期个数（与中断计数同源）
- `N` = nHalf = n
- `t` = lastT（最近一次全周期估计）
- `G` = Tavg 对应的平均 g；`g` = lastT 对应的单次 g
- OLED 四行布局、err 角标、[测量中]/[待机]、sG 年龄标注全部不变

## 5. 验收（不变）

L = 1.000 m、sG ≈ 9.794（张家口）时，Tavg ≈ 2.007 s；
连续 3 组测量 Gavg 相对偏差 ≤ 0.5%。
