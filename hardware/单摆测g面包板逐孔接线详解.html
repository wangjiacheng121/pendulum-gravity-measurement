〇、为什么有 V2？（与旧版的差异）

实物采购后发现：本轮买到的 15mm 宽槽光电门是 5V 专用（不能接 3.3V），且其 OUT 引脚空闲时输出 5V 高电平——直接进 ESP32 的 GPIO4 有过压风险。因此电气架构升级为「双电源轨 + 电平转换」：

项目旧版（V1）V2（本页，以实物为准）
电源架构单 3.3V 轨，光电门直接吃 3.3V顶轨 3.3V（ESP32 / OLED / 电平转换 VCCA）＋ 底轨 5V（MB102 电源模块供电，光电门 VCC / 电平转换 VCCB）
光电门信号OUT 直连 GPIO4OUT（5V 逻辑）→ 8 路 BSS138 电平转换模块（只用 A0/B0 一路）→ GPIO4（3.3V 逻辑）
主板列位左 b 列 / 右 h 列经典 MB-102 槽宽 7.62mm → 主板落 d / h 类列对（b/h 仅适用窄槽板）
GPIO4 / 3V3 / GND 位置「左排 GND、3V3」的通用假设改按实物引脚图定标（见 §〇.6）：GPIO4=d21、GPIO5=d20、GPIO8=d16、GPIO9=d15、3V3=d8、GND=d18——关键信号全在 d 列

⚠️ 「5 孔条连通规则」不受列位影响，始终适用；但行号公式已随插向改变：本板脚 1 靠右端 → 第 n 脚 = 第 25−n 行（脚 1 = 第 24 行），见 §一 / §〇.6。变的只是列位、行公式和电源域。

〇.5 电源模块安装方向已锁定（正插 = 红正 · 蓝负）

你的实物是经典 MB-102 面包板 + MB102 电源模块。这两个特性已在本方案里直接拍板，不再需要万用表实测极性：

🔒 两条电源轨的电压已定死：顶轨（板上边缘那对红 / 蓝印刷线）= 3.3V 域；底轨（板下边缘那对红 / 蓝印刷线）= 5V 域。与其对应的模块跳线：顶跳线 OFF（顶轨不靠模块供电，由 ESP32 的 3V3 引脚供）、底跳线 5V（底轨由模块供 5V）。红印 = 正、蓝印 = 负（正插锁定后全板通用）。
特性（卖家标注）本方案的硬性规定为什么安全
① 模块可正插 / 反插，极性会翻转
卖家标注：正插→红正蓝负；反插→蓝正红负		✅ 一律「正插」：模块的 +/− 标记对准面包板红 / 蓝线（模块 + 针插红轨、− 针插蓝轨）。自此刻起全板印刷红=正、蓝=负，永久可信，不要再量。方向是我定的，不是你量的。装模块时低头看一眼模块 +/− 丝印对齐红蓝线，极性就锁死，不可能翻。
② 面包板中间断开：内部无线路连通，分成两段✅ ⑰⑱ 桥线 + 两条 − 轨桥线本板必接（顶−、底− 同样断开，一并桥），见 §四。这是板子内部物理结构，跟极性无关，桥完即通。

安装一步到位（代替原来的「校准五步」）

第 0 步 · 正插锁定：把 MB102 插入面包板左端（第 1 行端，不挪动）电源轨，确认模块的 +/− 标记正对红 / 蓝线（正插），拨跳线 顶跳线 OFF、底跳线 5V。插好后红=正、蓝=负即锁定。再用万用表通断档只量一件事：底+ 轨最左对最右是否导通（中段断开 → 记下要补 ⑱；− 轨同理补黑线桥；顶轨通电后按 §六第 4 步再量）。极性无需再量。
📏 模块插在哪一端？（按你的决定：留在第 1 行端 · 不挪动）MB102 插在面包板任一端电气上都行（两条电源轨靠 ⑰⑱ 桥线贯通全板）。既然模块固定在第 1 行端（本体横跨约 3 行，会挡住那一端的孔位），本方案把光电门改到右端 c61–c63（第 63 行端，除电源轨外全是空行，不挡 ESP32 的 USB 线）；④⑤⑥ 三根线相应加长即可。ESP32 / OLED / 电平转换布局不变。
🚫 两条铁律（正插下仍然成立）：① 光电门 严禁接顶轨（5V 专用，只进底+）；② MB102 顶跳线必须 OFF——误拨 5V 会把 5V 灌进顶轨（顶轨由 ESP32 3V3 定义），威胁 ESP32 / OLED。若上电即烧 / 发烫，先查顶跳线是否被误拨 5V，再查模块是否反插（拔下转 180° 重插成正插）。
💡 「红=正蓝=负」现在成立的条件：仅当模块「正插」——即模块的 + 针在红轨、− 针在蓝轨。装模块时低头看一眼模块上的 +/− 丝印对齐红蓝线即可，一眼的事，不用电表。
📐 顺带确认板型：MB-102 标准款为 830 孔（63 列，约 16.5×5.5cm）。若你手上实际是 400 孔小半板（30 列，约 8.3cm），ESP32-S3（约 20 列）＋电平转换模块（10 列）无法同板容纳，需两块并排——量一下长度即可确认。本页示意图按 830 孔绘制。
🔌 供电输入：用 USB 口供电时输入 = 5V（模块正常工作范围）；若改用 DC 圆头输入，必须 7–12V——过低（<7V）会导致输出不足、过高可能烧毁模块（卖家原话）。本项目一律走 USB，省事又安全。

〇.7 不用 MB102、全由 ESP32 供电可行吗？（单电源方案）

问题本质：能否把 V2 里「底轨 5V 由 MB102 专供」改成「底轨 5V 也由 ESP32 开发板的 5V 脚供给」，从而拔掉 MB102、整板只留一根 USB-C 线。结论：完全可行，且更简单。下面给论据与改法。

为什么可行（电气事实）

事实说明
本板自带 5V 脚立创 ESP32-S3（A 排 17–19 脚 = h8 / h7 / h6）就是 USB VBUS 直出的 5V 输出脚（经保护二极管，实测约 4.7–5.0V）。它本来就在板上，V2 只是为「不混入第二路 5V」而没用。
3.3V 域本来就是 ESP32 供V2 顶轨 3.3V 已从 ESP32 3V3 脚（d8）取，没变。单电源只是把 5V 源从 MB102 换成板载 5V 脚，两域仍同源（同一颗 USB）。
负载极小，余量巨大全系统稳态电流仅约 0.2–0.35 A（见下方电流预算），任意 USB 口（≥0.5A）都绰绰有余。

⚠️ 单电源方案下请通过 USB-C 给板子供电（此时 5V 脚作输出）；不要再从 5V 脚反向灌电。

需要注意的 4 点

1) 单点供电：全部依赖这一根 USB-C 线/头，断一根全板停。但本 proj 总电流仅 0.2–0.35A，普通线材/充电头都行，风险极低。
2) 板载 5V 脚是 VBUS（经保护二极管 ~4.7–5.0V），光电门 5V 标称仍在其容差内；千万别再从别处灌 5V（当初引入 MB102 正是怕「两路 5V 打架」，现在只剩一路，反而不用担心）。
3) ③ 从条件变必接：务必把顶−（ESP32 GND）与底−（光电门/电平转换 GND）接通，否则 5V 域地悬空、计数乱跳。
4) 失去 MB102 的螺丝端子/桶形座独立 5V 入口与双电源冗余；若以后要带大电流外设（电机、大屏、多传感器）再外接 MB102/独立 5V，当前不需要。
✅ 结论：可行，且更省事（少一个模块、少一根线、少一处极性/共地坑）。推荐作为默认方案；V2（MB102）留作「需要更大 5V 电流时的备选」。采用单电源后，§〇.5 的 MB102 正插/跳线设置整段不再适用；底轨 5V 直接由板载 5V 脚供给，红印=正仍对应底+，无需极性实测（来源唯一且已知）。

MB102 电源模块插面包板左端（第 1 行端，即你现在的位置）的电源轨，本体横跨约 3 行，不挪动正插（模块 +/− 标记对齐红/蓝线）、顶跳线 OFF、底跳线 5V；USB 口朝外接充电头/充电宝。挡住第 1 行端孔位，故光电门改到右端 c61–c63
轻触按键不插板，对角两脚用母对母线引出按下导通的那对；可用双面胶贴在板边
🎨 示意图约定：红线 = 所有「+」轨（顶 3.3V / 底 5V），蓝线 = 所有「−」轨；3.3V 域与 5V 域靠「顶轨 / 底轨」位置区分，不靠颜色。正插锁定后板子红印=正、蓝印=负，与图完全一致。

四、逐根接线清单 V2（15 必接 + 3 桥线 = 18 根；桥线本板均需接）

#线色从到作用 / 电源域
①红ESP32 3V3（d8，落 a8）顶 + 轨主控输出 3.3V 给顶域
②黑ESP32 GND（d18，落 a18）顶 − 轨主控共地
③黑·条件顶 − 轨底 − 轨两域共地桥：MB102 装好后量顶−对底−，已导通则免接
④红光电门 VCC 行底 + 轨（5V）光电门供电（5V 专用，禁接顶轨！）
⑤黑光电门 GND 行底 − 轨光电门共地
⑥黄光电门 OUT 行B0 所在行同条空孔挡光信号（5V 逻辑）进电平转换
⑦红VCCB 行底 + 轨电平转换 5V 侧供电
⑧红VCCA 行顶 + 轨（3.3V）电平转换 3.3V 侧供电（必接，模块无板载稳压）
⑨黑电平转换 GND 行底 − 轨模块共地（两排 GND 内部相通，接一个即可）

⑭绿OLED SCL 行（c32）GPIO9（d15）I²C 时钟

⑱红·本板必接底 + 轨左端底 + 轨右端桥接底+（MB102 供电距离长）；底− 轨同理补一根黑线桥
红黑域规则（复查口诀）：红线只允许出现在 {顶+域：①⑪⑧} 和 {底+域：④⑦} 两个圈子里；黑线全部归 − 轨（②⑤⑨⑫⑯ + 条件③）；同一行上红线和黑线绝不碰面。
「GPIO x 所在行」怎么找？三步：
1) 在板子丝印上认出引脚序号（B 排 01 … 14 RST 3V3 / A 排 46 … 48 BOOT 5V）；
2) 用公式换算行号：第 1 脚 = 第 24 行，则第 n 脚 = 第 25−n 行；
3) 该行的其它空孔（同条 a–e 五孔内任一）就是接线点，绝不能插到相邻行。
本板实测参考：GPIO4=d21、GPIO5=d20、GPIO8=d16、GPIO9=d15、3V3=d8、GND=d18（详见 §〇.6）——旧交接文档里的 j7/j9/j11/j13 已作废，以本节 + 实物丝印为准。
⚠️ 杜邦线两端都要插到底，虚接是新手最常见的「程序没问题但不工作」原因。③号共地桥在 MB102 装好后再决定接不接——先量，导通就不接。

五、到货自检：「丝印四认」

器件要认什么注意事项
光电门3 针丝印顺序（VCC/GND/OUT）历史有两种：GND-OUT-VCC / OUT-GND-VCC，以实物为准；确认是 5V 供电款；挡光片过槽 ≤12mm、不透光
OLED4 针丝印顺序本轮实物为 GND-VCC-SCL-SDA；驱动芯片 SH1106（1.3″ 屏专用），需 SH1106 专用库（Adafruit_SH1106 或 U8g2），不可直接用 SSD1306 库；I²C 地址 0x3C（失败试 0x3D）；模块 I²C 4 针、已焊排针
电平转换模块VCCA / VCCB / A0 / B0 位置必须已焊排针（散针版要么退货要么补焊）；认准 A0/B0 与其它 A1–A7/B1–B7 的位置区别
轻触按键「对角导通」的两脚用万用表通断档确认：按下导通、松开断开的那一对

六、分步装配与验证（每步都验，最后通电）

第 0 步 · 正插锁定（见 §〇.5）：MB102 正插（模块 +/− 标记正对红 / 蓝线）、插在第 1 行端（即你现在的位置，不挪动），顶跳线 OFF、底跳线 5V → 红=正蓝=负即锁定。万用表通断档量底+ 轨是否中段断开（本板要补 ⑱，− 轨同理补黑桥）。断电后再进入第 1 步。极性不用量、不用贴标签。
第 1 步 · 断电插主控：确认两根 USB 均未接。B 排（印 01 … 14 RST 3V3）朝 a–e 侧 → 落 d 列；A 排朝 f–j 侧 → 落 h 列；脚 1 靠右端（第 24 行），跨插中间槽占第 5–24 行，USB-C 朝右（避开左端 MB102）。核对每脚入孔、无弯脚悬空。
第 2 步 · 标行号：对照丝印标出 d21=GPIO4、d20=GPIO5、d16=GPIO8、d15=GPIO9、d8=3V3、d18=GND（公式 25−n）。这步最容易错，务必数两遍。
第 3 步 · 插电平转换模块：行 38–47 试摆跨槽；贴便利贴标出 VCCA 侧（朝顶轨方向）和 VCCB 侧（朝底轨方向），防止接反。
第 4 步 · 接顶轨域：插 ①②（3V3→顶+、GND→顶−）、⑧（VCCA→顶+）、⑪⑫（OLED 电源）。验证：顶+ 对顶− 不导通；3V3 行对顶+ 导通；VCCA 行对顶+ 导通。
第 5 步 · 插 OLED 并接信号：按丝印 GND-VCC-SCL-SDA 插 c30–c33（c30=GND、c31=VCC、c32=SCL、c33=SDA；USB-C 占用右端 25–27 行，故 OLED 移到 30–33 行避让），接 ⑬（SDA→GPIO8 即 d16）、⑭（SCL→GPIO9 即 d15）。SDA/SCL 别接反。
第 6 步 · 接按键：对角两脚先确认「按下导通」，再接 ⑮⑯。
第 7 步 · 插光电门并接底轨域：光电门插 c61–c63（右端，避让左侧模块）（丝印逐针认），接 ④（VCC→底+）、⑤（GND→底−）、⑥（OUT→B0 行，线加长）；再接 ⑦（VCCB→底+）、⑨（模块 GND→底−）。再三确认光电门没有接到顶轨。
第 8 步 · 桥接 + 共地复查：按第 0 步记录补 ⑰（顶+ 中段）⑱（底+ 中段）；− 轨若分段同样补黑线桥。万用表量顶− 对底−：导通则免接③（模块已内部共地），不导通则插③号共地桥。
第 9 步 · 通电前复查：按红黑域口诀过一遍所有线；万用表电阻档测顶+对顶−、底+对底− 均 >1kΩ；顶+ 对 底+ >1kΩ。
第 10 步 · 先上 3.3V 域：只插 ESP32 的 USB。预期：顶+ ≈ 3.3V、OLED 亮并显示「[待机]」、A0 行 ≈ 3.3V。若 OLED 不亮，先查 ⑪⑫⑬⑭。
第 11 步 · 再上 5V 域：MB102 USB 接充电头。预期：底+ ≈ 5.0V、VCCB 行 ≈ 5V、VCCA 行仍 ≈ 3.3V、光电门 OUT 行 ≈ 5V。
第 12 步 · 验证电平翻译与联调：万用表测 A0 行：无挡光 ≈ 3.3V、挡光 ≈ 0V → 说明⑥⑩正确。然后在光电门间手动挡一下光，OLED 的 n 计数 +1；按键开始/停止正常。通过后按主方案文档进行摆长设置与测量。
