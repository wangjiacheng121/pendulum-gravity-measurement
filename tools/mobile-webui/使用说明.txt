二、重要原理（30 秒读完，避免走弯路）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Operit 的 Ubuntu 是 chroot/proot 容器，没有蓝牙控制器访问权，
  所以 python + bleak（ble_cli.py）在手机上跑不了，root 也无解。
  本工具改用 Chrome 的 Web Bluetooth：由 Chrome 直接调系统蓝牙，
  Operit 的 Ubuntu 只负责起一个本地网页服务。因此：

  * 必须用 Chrome / Edge 等 Chromium 内核浏览器（小米自带浏览器不行）
  * 必须通过 http://127.0.0.1:8000 打开（直接点开 html 文件不行）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、安装与启动（5 步）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 把整个「手机端工具包」文件夹拷到手机存储
     （例如 Download/手机端工具包；若 Operit 终端访问不了
      sdcard 路径，就把文件夹复制进 Operit 工作区目录）

  2. 打开 Operit → 终端（Ubuntu），执行：
        cd /你的路径/手机端工具包
        sh 启动服务.sh
     出现 "pendulum-g 本地服务已启动" 即成功。
     （若提示 python3 不存在：apt update && apt install -y python3）

  3. 打开 Chrome，地址栏输入：
        http://127.0.0.1:8000/ble_cli_web.html
     （服务开着才能访问；可收藏此地址）

  4. 开发板上电。点页面顶部「连接 pendulum-g」，
     在系统弹窗里选中 pendulum-g 设备。

  5. 之后所有操作在「终端」卡片进行，和 PC 版 ble_cli.py
     完全一样——看板子的提示输出，照着输入即可。

六、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q: 打开网页提示无法访问？
     启动服务.sh 必须保持运行。终端被关了就重新执行第 2 步。

  Q: 点连接没反应/不支持？
     确认用的是 Chrome；系统设置→应用→Chrome→权限→
     「附近设备」设为允许。

  Q: 扫不到 pendulum-g？
     板子重新上电；确认没被 nRF Connect 等 App 占用。

  Q: 连上但终端没输出？
     随便发一个 0 试试。

  Q: 波形卡顿/断流？
     保持 Chrome 页面在前台；给 Chrome 的省电策略设为「无限制」。
     页面会自动申请屏幕常亮，勿手动锁屏。

  Q: 导出中途断了？
     20 秒收不到数据会自动按已收到的部分保存（和 PC 版一样），
     重新发 3.2 即可重导。
