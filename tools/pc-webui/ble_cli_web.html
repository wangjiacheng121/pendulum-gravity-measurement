运行说明

电脑端（Windows / macOS / Linux）：用 pc_web_server.py 启动 
pip install -r requirements.txt
python pc_web_server.py     # 浏览器自动打开 http://127.0.0.1:8777/
python pc_web_server.py AA:BB:CC:DD:EE:FF   # 指定地址直连

蓝牙由本机 Python（bleak）接管，页面通过 SSE 实时收行，UI 与手机版完全相同。没接开发板时可点「服务自检」按钮——后端会注入脚本化波形与导出数据，用来验证整条页面链路（Excel/绘图/波形都在浏览器里完成，与硬件无关）。

为什么不在手机 Ubuntu 里直接跑 ble_cli.py？

手机里的 Ubuntu（proot/chroot 容器）没有蓝牙控制器访问权：Android 的蓝牙栈独占射频芯片，容器内既没有 hci0 也没有 BlueZ D-Bus，Python 的 bleak 库因此完全扫不到设备——root 也无法优雅解决（需要停掉 Android 蓝牙、在内核层 hciattach，逐机型不同且极脆弱）。
本页改用浏览器的 Web Bluetooth API：Chrome 直接调用 Android 系统蓝牙栈，权限、连接管理都由系统处理，功能与 PC 版 ble_cli.py 一致。

启动步骤（Ubuntu 环境内） 
cd /path/to/firmware/TaskManagerFirmware/tools
python3 -m http.server 8000

然后用 Chrome / Edge 等 Chromium 内核浏览器打开：

http://127.0.0.1:8000/ble_cli_web.html

① Web Bluetooth 只在 https 或 localhost 下可用，所以必须经本地服务打开，直接点开文件（file://）不行；② 小米自带浏览器可能未开放 Web Bluetooth，请用 Chrome；③ 下载的文件在手机「下载/Download」目录。

常用操作流程（与 PC 版一致） 
配网：  1 → 看WiFi列表输序号 → 输密码
摆长：  2 → 2.2 → 输新摆长 → y 确认
海拔：  2 会话内：alt 500
导出：  3 → 3.2 → 自动收数+下载Excel+T²-L图
清空：  3 → 3.3 → CLEAR
天气：  4 → 4.1状态 / 4.2坐标 / 4.3更新 / 4.4 Key+Host
模拟：  APP 2 → SIM ON（测完 SIM OFF 自动结算入库）
波形：  APP 2 → STREAM ON → 板上短按键开始 → 实时曲线
常见问题

· 扫不到设备：开发板重新上电；确认没被 nRF Connect 等 App 占用；浏览器蓝牙权限（系统设置里）已允许。
· 连上但无输出：随便发个 0。
· 波形时息屏会断流：波形卡片会自动申请屏幕常亮；若仍中断，请在系统设置给浏览器「无限制」省电策略。
· 导出中断：20 秒无新数据会自动按已收到的部分数据落盘（与 PC 版看门狗一致）。
