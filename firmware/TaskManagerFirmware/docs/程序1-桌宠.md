# 程序1：桌宠屏保（AppId::PET）

## 概述

桌宠是系统的**默认程序**——开机即激活、屏保 home 目标、长按循环归位点。

## 功能

| 功能 | 说明 |
|---|---|
| 颜文字表情 | `(^o^)/` 打招呼 → `(^^)` 待机慢眨眼 → `(-.-)` 瞌睡（5min idle）→ Zzz 睡眠 |
| 事件联动 | 程序2 测量完成时自动切换庆祝表情；网络连接/断开也有反应 |
| 按键交互 | 短按换表情（随机状态轮转）|
| AI 桩 | BLE [5] 菜单已注册，但仅返回"功能开发中"（需麦克风+功放硬件，暂不实现）|
| RSS 新闻 | 分册01 可选模块 A，接口已预留，未实现 |

## 状态机

```
IDLE (待机) ──短按──→ HAPPY / LOVE / ANGRY / SAD (随机)
    │                    │
    │ 5min 无操作       │ 5min 无操作
    ↓                    ↓
SLEEPY (瞌睡) ──1min──→ 请求熄屏 (L3)
    ↑                        │
    └──── 唤醒/按键 ─────────┘
```

## NVS 键

| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| app1.pet_mood | string | "IDLE" | 当前表情状态（仅 IDLE/SAD/SLEEPY 写入，避免 NVS 磨损）|

## BLE 菜单

| 命令 | 功能 |
|---|---|
| [5] | AI 问答（桩，返回"开发中"）|

## 文件

- `app1_pet.h` —— 类声明与状态枚举
- `app1_pet.cpp` —— 表情状态机 / 事件联动 / BLE [5] 桩

## 与其他程序的关系

- 接收 `EVT_MEASURE_DONE` → 庆祝表情
- 接收 `EVT_BLE_CONN` / `EVT_BLE_DISC` → 连接状态表情
- 屏保超时（`sys.screen_saver_timeout`，默认 180s）自动切回本程序
