一、包内容
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  pc_web_server.py    后端：bleak 接管蓝牙 + 本地网页服务（零第三方 Web 框架）
  ble_cli_web.html前端页面（与手机端**完全同一个文件**，UI 一致）
  启动服务.bat         Windows 一键启动（双击即可，自动装依赖、自动开浏览器）
  requirements.txt    依赖清单（实际只需 bleak）
  使用说明.txt        本文件

  可选：pc_webui_selftest.png 是页面自检时的截图（可删）

二、最快上手（Windows）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 双击「启动服务.bat」
     （首次会自动 pip install bleak；若无 Python 会提示安装地址）
  2. 浏览器自动打开 http://127.0.0.1:8777/
     没自动打开就手动复制这个地址到浏览器
  3. 开发板上电 → 点页面「连接 pendulum-g」
     扫不到就把板子重新上电，或点「重新扫描（全部设备）」
  4. 之后照页面终端提示操作，和 ble_cli.py 完全一样

  macOS / Linux：
     pip install bleak
     python3 pc_web_server.py
     浏览器打开 http://127.0.0.1:8777/

  指定地址直连（避开扫描）：
     python pc_web_server.py AA:BB:CC:DD:EE:FF
     python pc_web_server.py AA:BB:CC:DD:EE:FF --port 9000

三、没接开发板也能先试：服务自检
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  点页面上的「服务自检」按钮，后端会注入一段脚本化数据：
     菜单/状态输出 → 60 帧 #STREAM 波形 → #EXPORT 历史 3 组
  预期看到：终端刷屏、波形三行曲线（T / 即时 g / 平均 Gavg）、
            表格 3 行、T²–L 图自动绘出、拟合 g ≈ 9.8、
            浏览器下载目录出现 pendulum_history_*.xlsx
  这一步验证的是「页面 + 导出 + 绘图」整条链路，与硬件无关。

  注意：自检数据只用于验证页面功能，不是真实物理测量结果。

四、功能清单（与 ble_cli.py / phyphox_stream.py 对齐）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  连接 pendulum-g / 重连上次 / 全扫描 / 断开
  0 状态总览            1 配网（列WiFi→选→密码）
  2 摆长 2.1 查看 / 2.2 修改（y 确认）   会话内 alt <米> 改海拔
  3 历史 3.1 预览 / 3.2 导出全部 / 3.3 清空（CLEAR）
  4 天气 4.1 状态 / 4.2 坐标 / 4.3 更新 / 4.4 Key+Host
  APP 1/2/3 远程切程序   SIM ON / SIM <秒> / SIM OFF  模拟自测
  STREAM ON/OFF 实时波形：T / g_inst / Gavg 三曲线、seq 丢帧告警、
                        帧数/Tavg/Gavg/数据率统计、波形 CSV 导出
  导出：20s 看门狗（同 PC 版）→ 自动下载 Excel + CSV + T²–L 图 PNG，
        表内数值型单元格直接可算
  快捷按钮：终端输入框下方一点即发；q 退出会话

六、常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q: 端口被占用（Address already in use）
     A: 换端口：python pc_web_server.py --port 9000

  Q: 页面打开了但一直「连接中」
     A: 开发板未上电或被别的 App 占用（nRF Connect 等）→ 上电后重连

  Q: 页面开着没反应
     A: 后端窗口被关掉了。关掉终端即停止服务，需重新运行

  Q: 想在手机上也用同一套界面
     A: 用手机端包（ble_cli_web.html + python3 -m http.server + Chrome），
        页面会自动识别：发现本机后端走后端模式，否则走 Web Bluetooth

  Q: 数据文件在哪
     A: 浏览器下载目录（Excel / CSV / PNG）
